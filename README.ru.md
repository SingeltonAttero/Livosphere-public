# Livosphere

Живые обои и виджеты часов для Android. Автор приложения — **Вебер Яков / Yakov Weber**.

Локальная витрина авторских сцен и часов S/M/L. Обои и виджеты устанавливаются независимо; их можно сочетать между коллекциями. Текущий состав manifest — 13 публичных коллекций. Продукт предназначен для телефона.

## Сборка

Нужны JDK 17 и Android SDK Platform 37. Из корня репозитория:

```sh
make doctor
make phone
```

Debug APK: `android/hub/app/build/outputs/apk/debug/app-debug.apk`. Ключ автора и BMAD для этой сборки не требуются. [Подробности и проверки](docs/BUILDING.md).

## Разработка

Код, тесты, скрипты и навыки находятся в репозитории. [Настройка агентских инструментов на другом устройстве](docs/AGENTS-SETUP.md) восстанавливает BMAD `6.11.0` локально; старый архив планирования в публичную поставку не входит. Новый вклад начинается с документации и текущего кода, не с восстановления приватных файлов.
