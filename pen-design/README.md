# Рабочий дизайн pen.dev

Актуальный редактируемый исходник — [Дизайн Живых обоев.pen](./Дизайн Живых обоев.pen). Он перенесён из исходной рабочей копии без изменения байтов. В нём находятся хаб, коллекции обоев/часов и материалы RuStore; связанные локальные файлы сохранены в `assets/`, `fonts/` и рядом с документом. Старые fixed/screen-only `.pen` snapshots и backup-файлы не перенесены.

Открывайте `.pen` в pen.dev. Агент читает и редактирует его через Pencil MCP, а не через текстовый редактор. Внешний вид приложения, дизайн-макет и установленный WallpaperService/AppWidget остаются разными артефактами.

Области: `hub`, `wallpapers/<id>`, `widgets/<id>`, `sets/<id>`. Node IDs и ревизии связывайте с [UX-документами](../docs/ux/SCREENS.md) и [картой происхождения](../docs/development/pencil-wallpaper-source-map.md). Android source assets находятся отдельно в `android/sets/`: перенос дизайна не меняет автоматически ресурсы сборки.

[Manifest переноса](source-manifest.json) фиксирует байты рабочего `.pen` и локальных dependencies. Все 83 ссылки на изображения текущего документа проверены через Pencil MCP; файлы доступны локально. Изменение арта требует согласования точной ревизии.

В файле сохранены обе области: `w7QBW` — fixed V1, `FXZpB` — рабочий редизайн V2. Наличие рабочей области не означает её принятия; статус определяется связанным согласованием точной ревизии.

## Что коммитить

Рабочий `.pen`, необходимые ассеты, описание и согласования. Временные экспорты и резервные копии — `.local/`, либо игнорируемые `exports/`, `backups/`, `tmp/`, `.working/`. Не создавайте новую копию дизайна на каждую мелкую правку: историю хранит Git. Принятый новый дизайн и его документация обновляются в одном MR.

Авторский арт регулируется [ASSET-LICENSE.md](../ASSET-LICENSE.md). Сторонние шрифты сохраняют собственные права; `fonts/localhost/e703a0eba8854daf.woff2` идентифицирован по таблице имён как Inter, Copyright 2020 The Inter Project Authors; [SIL OFL 1.1](../docs/licenses/Inter-OFL.txt). Для нового контента используйте шрифты с зафиксированной лицензией и provenance.

## Проверка публичного состава

Gitleaks 8.30.1 отметил единственное поле `fileToken` как generic-api-key. Проверка установленного Pen.app показывает: `createFileToken()` генерирует UUID через `crypto.randomUUID()`, а owner share/comment API отдельно требует session `authToken`. Это идентификатор документа, не API-ключ и не ключ подписи. Значение не приводится в документации; широкое исключение `.pen` из secret scanning не добавлялось. Этот вывод относится к проверенному snapshot, новые изменения проверяются заново.
