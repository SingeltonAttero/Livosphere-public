# Лес после дождя — техническая запись приёмки

Владелец 2026-09-24 принял все 40 текущих Pencil-кадров как есть и следующим сообщением разрешил разработку. Для этого продукта приняты точные узлы `eOUcx`, `cE7TM`, `tR9bI`, `GU47O`; изменение их bytes требует новой художественной приёмки.


Объём приёмки: AP-IMAGE для статичного debug-импорта. Public/release, физическое устройство, OEM LOCK и будущая анимация не приняты.

2026-09-26: владелец расширил объём этой приёмки на public phone release — обои входят в принятый состав release candidate (13 наборов: 10 Pencil + 3 neon). Физическая производительность, батарея, OEM LOCK, магазинные проверки и публикация остаются отдельными проверками выпуска и здесь не подтверждаются.
