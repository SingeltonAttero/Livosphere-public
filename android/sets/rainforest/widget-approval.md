# Лесной круг — техническая запись AP-HTML

Владелец 2026-09-24 принял все десять часов Pencil V1 для Android сообщением «Принимаю все 10, делай Android». Для `rainforest` принята стрелочная композиция «Лесной круг» из фреймов `lBEwq`, `Uzm34`, `Dqhi6` и общего `review-v1.html`.

Native-реализация использует системный `AnalogClock` с авторскими dial/hour/minute drawables. M/L добавляют живые `TextClock` для отдельного дня недели, числа и месяца. Cormorant Garamond включён без изменений из официального каталога Google Fonts под SIL Open Font License 1.1.

Объём: `AP-HTML` для debug-only Android AppWidget S/M/L. Физическая проверка и `AP-native` остаются за владельцем.
