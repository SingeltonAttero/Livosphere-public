# Кварталы — техническая запись AP-HTML

Владелец 2026-09-24 принял все десять часов Pencil V1 для Android сообщением «Принимаю все 10, делай Android». Для `moscow-facets` принята цифровая композиция «Кварталы» из фреймов `QrBl3`, `MLeSu`, `Pa9GK` и общего `review-v1.html`.

Native-реализация использует системные `TextClock` для часов, минут, периода и даты. Space Grotesk включён из официального каталога Google Fonts под SIL Open Font License 1.1. Период AM/PM добавлен только для 12-часового формата как заранее отмеченная native-адаптация раздельных цифр.

Объём: `AP-HTML` для debug-only Android AppWidget S/M/L. Физическая проверка и `AP-native` остаются за владельцем.

2026-09-26: владелец расширил объём этой приёмки на public phone release — часы S/M/L входят в принятый состав release candidate (13 наборов: 10 Pencil + 3 neon). Физическая проверка, `AP-native` на устройстве и публикация остаются отдельными проверками выпуска и здесь не подтверждаются.
