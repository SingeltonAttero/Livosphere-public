# Эскиз — техническая запись AP-HTML

Владелец 2026-09-24 принял все десять часов Pencil V1 для Android сообщением «Принимаю все 10, делай Android». Для `synthetic-dawn` принята цифровая композиция «Эскиз» из фреймов `TyPYm`, `VhqU8`, `dQN6r` и общего `review-v1.html`.

Native-реализация использует живые системные `TextClock`: единое время для S/M/L и объединённую локализованную дату для M/L. Manrope включён без изменений из официального каталога Google Fonts под SIL Open Font License 1.1; дополнительный текст использует системный Roboto.

Объём: `AP-HTML` для debug-only Android AppWidget S/M/L. Физическая проверка и `AP-native` остаются за владельцем.
