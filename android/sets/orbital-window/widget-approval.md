# Орбита — техническая запись AP-HTML

Владелец 2026-09-24 принял все десять часов Pencil V1 для Android сообщением «Принимаю все 10, делай Android». Для `orbital-window` принята стрелочная композиция «Орбита» из фреймов `dnYIk`, `m4SBgo`, `sagao` и общего `review-v1.html`.

Native-реализация использует системный `AnalogClock` с авторскими dial/hour/minute drawables и системные `TextClock` для даты. Manrope включён из официального каталога Google Fonts под SIL Open Font License 1.1.

Объём: `AP-HTML` для debug-only Android AppWidget S/M/L. Физическая проверка и `AP-native` остаются за владельцем.

2026-09-26: владелец расширил объём этой приёмки на public phone release — часы S/M/L входят в принятый состав release candidate (13 наборов: 10 Pencil + 3 neon). Физическая проверка, `AP-native` на устройстве и публикация остаются отдельными gates Epic 14 и здесь не подтверждаются.
