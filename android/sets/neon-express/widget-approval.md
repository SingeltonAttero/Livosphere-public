# Перрон — техническая запись AP-HTML

Владелец 2026-09-24 принял все десять часов Pencil V1 для Android сообщением «Принимаю все 10, делай Android». Для `neon-express` принята цифровая композиция «Перрон» из фреймов `O0uk84`, `ACHHQ`, `xbKta` и общего `review-v1.html`.

Native-реализация использует раздельные живые системные `TextClock` для часов и минут, отдельный индикатор периода в 12-часовом режиме и объединённую локализованную дату для M/L. Space Mono Bold включён без изменений из официального каталога Google Fonts под SIL Open Font License 1.1.

Объём: `AP-HTML` для debug-only Android AppWidget S/M/L. Физическая проверка и `AP-native` остаются за владельцем.
