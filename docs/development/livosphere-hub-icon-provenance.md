
# Provenance значка хаба Livosphere

`ic_launcher_foreground.xml`, `ic_launcher_background.xml` и `ic_launcher_monochrome.xml` созданы в этом репозитории 2026-09-08 для оболочки хаба. Знак не использует палитру или ассеты набора «Контур» и не воспроизводит чужую интеллектуальную собственность.

2026-09-25 — знак заменён на арт **«Живой мир»** из pen.dev V1 (`Дизайн Живых обоев.pen`, фрейм `FU0ad` «RuStore · Иконка приложения · 512 × 512», мастер `beaY1`, image fill `generated-14.png`, 1024×1024). Полный арт размещён как adaptive foreground (`@mipmap/ic_launcher_foreground`) с центровкой в safe-zone; фон — `@color/ic_launcher_background` `#0C0824` (тон из арта); monochrome — упрощённый векторный силуэт орбитальной сферы. Legacy PNG (mdpi–xxxhdpi) сгенерированы из того же арта. Чужая IP не используется.

2026-09-25 (позже) — владелец нарезал в pen.dev полный комплект `03 · Android / Полный комплект иконки приложения`. Обновлено: adaptive foreground → прозрачный арт `generated-11.webp` (фрейм `RpPdv`, 480×480, fit); background → `#100D29` (фрейм `Kd1TT`); monochrome → векторный path `kh3bq` из фрейма `EomWv` (точная geometry, заменяет упрощённый силуэт). Legacy square/round всех плотностей остаются из полного арта `generated-14.png`. Checkpoint: `checkpoint-hub-icon-update-2026-09-25.md`.
