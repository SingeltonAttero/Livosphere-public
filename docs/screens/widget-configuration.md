# Карточка и настройка часов

Экран отвечает за выбор размера и действия по нажатию. Он работает в двух режимах: добавление часов и редактирование конкретного экземпляра.

## Добавление

1. Каталог открывает карточку выбранных часов с названием и native-превью.
2. Пользователь выбирает S/M/L и приложение часов, которое будет открываться по нажатию. Можно оставить «Выбрать позже».
3. «Установить» отправляет запрос launcher и открывает системное подтверждение.
4. Если автоматическое добавление недоступно или отклонено, экран объясняет ручной путь через список виджетов и предлагает перейти на главный экран.

Запрос на добавление ещё не означает, что виджет размещён. Отмена не меняет соседние экземпляры.

## Редактирование

Открывается из списка экземпляров или системного добавления виджета. Показывает оформление, действие по нажатию и доступные параметры конкретного Android widget ID. Размер закреплён выбранным provider, если Android передал его при создании.

«Сохранить» сохраняет конфигурацию и обновляет этот экземпляр. «Отмена» закрывает экран без нового сохранения. При ошибке чтения или записи экран сообщает о ней. Если обновить RemoteViews не удалось, приложение пытается восстановить прежнюю конфигурацию; результат восстановления показан пользователю.

S показывает время. M/L показывают время и дату. Стрелочный/цифровой стиль задаётся самим оформлением.

## Где менять

`android/hub/app/src/main/java/app/livosphere/widgets/ClockWidgetActivities.kt`; сохранение, pin-запросы и обновление — в `android/widgets/runtime`.

Новые параметры храните по widget ID. Не меняйте все экземпляры при редактировании одного.

## Проверить

Добавить два экземпляра разных часов, изменить действие одного, отменить изменение второго. Проверить S/M/L и ручное добавление из списка launcher.
