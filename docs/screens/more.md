# Ещё

Раздел объединяет вспомогательные действия:

- «Настройки» — управление обоями и движением интерфейса.
- «Помощь с установкой» — состояние обоев и размещённые экземпляры часов.
- «Как установить» — диалог инструкции.

Настройки и помощь открываются вложенными экранами; Back возвращает в «Ещё». Инструкция закрывается поверх текущего экрана.

Код: `android/hub/app/src/main/java/app/livosphere/hub/more/MoreScreen.kt` и `hub/navigation/HubNavigation.kt`.

Новые справочные разделы можно добавлять здесь. Каталоги обоев и часов остаются основными вкладками.
