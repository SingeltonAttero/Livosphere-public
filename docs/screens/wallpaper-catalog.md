# Все обои

Экран показывает миниатюры всей включённой в сборку коллекции. Он нужен для быстрого выбора без последовательного листания.

## Поведение

Каждая карточка содержит превью, название и отметку выбранных обоев. Нажатие выбирает обои для просмотра и открывает экран «Обои». Системная установка здесь не запускается. Back возвращает к витрине. Позиция прокрутки хранится в состоянии экрана при переходах внутри приложения.

Отметка «Выбрано» относится к просмотру, а не к установленным обоям.

## Где менять

`android/hub/app/src/main/java/app/livosphere/hub/theme/WallpaperCatalogScreen.kt`. Данные предоставляет `AuthoredContentCatalog` из сгенерированного реестра.

Поиск, сортировку и фильтры можно добавить на этом экране, сохранив переход к выбранному превью.

## Проверить

Открыть «Все обои», выбрать карточку, вернуться в каталог. Выбор и название должны соответствовать открытым обоям; оформление телефона не меняется.
