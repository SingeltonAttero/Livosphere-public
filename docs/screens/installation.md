# Помощь с установкой

Экран объясняет, что Android сообщает о выбранных обоях, и позволяет настроить размещённые часы.

## Обои

Показываются название выбранного оформления, доступность живых обоев, наличие компонента и состояние применения на HOME/LOCK. Подробности раскрывают поддержку телефона, ограничения политики и доступность системной примерки или списка обоев. Если Android не даёт достоверного ответа, состояние отображается как неизвестное.

Сведения обновляются при возвращении в приложение и по запросу проверки. Приложение не делает вывод об установке только по результату закрытия системного экрана.

## Часы

Список содержит известные приложению widget ID, оформление, размер и признак необходимости настройки. «Изменить» открывает настройку этого экземпляра. Есть переход в каталог и инструкция по удалению через launcher. Приложение не удаляет соседние виджеты самостоятельно.

Известный widget ID не подтверждает, что часы видны на текущем рабочем столе. Ошибку чтения списка экран показывает отдельно от пустого списка.

## Где менять

`android/hub/app/src/main/java/app/livosphere/hub/devices/DevicesScreen.kt`, `WidgetInstances.kt` и `hub/wallpaper/AndroidWallpaperGateway.kt`.

Новые сведения должны приходить от Android или собственного хранилища с понятным источником. Не заменяйте неизвестное состояние сообщением об успехе.

## Проверить

Открыть после установки и отмены обоев, затем после добавления/удаления часов через launcher. Список и сведения должны обновиться без изменения других экземпляров.
