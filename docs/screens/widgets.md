# Виджеты

Отдельный каталог авторских часов. Обои устанавливать для них не требуется.

## Поведение

Вертикальный список показывает названия, оформление часов и доступные размеры S/M/L. Нажатие карточки открывает [карточку часов](widget-configuration.md). В списке нет отдельной кнопки установки. При пустой коллекции отображается сообщение. Позиция списка сохраняется при переключении вкладок.

Превью часов строится на основе native RemoteViews. Внешний размер и размещение готового виджета определяет launcher.

## Где менять

`android/hub/app/src/main/java/app/livosphere/hub/theme/WidgetFeed.kt`, `NativeWidgetPreview.kt` и `app/livosphere/widgets/RegistryWidgetCatalog.kt`.

Новые часы должны появляться через реестр контента. Каталог можно развить фильтрами по стилю или размеру; установки при выборе карточки происходить не должно.

## Проверить

Открыть часы из середины списка, вернуться, переключить вкладки. Список не должен создавать виджеты или менять уже размещённые часы.
