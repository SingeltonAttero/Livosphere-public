# Подписанная сборка

Для разработки используйте debug APK из [BUILDING](BUILDING.md). Следующие команды предназначены для владельца постоянного ключа.

1. Сделайте рабочее дерево Git чистым.
2. Скопируйте `.env.example` в `.env`, заполните локально и выполните `chmod 600 .env`. Ключ хранится вне репозитория.
3. Выполните `make release-candidate`.

Скрипт собирает подписанные APK/AAB, проверяет подписи и сохраняет копии с контрольными суммами в `.local/evidence/phone-v2/<run>/`. У него нет действия публикации.

```sh
make candidate-install PHONE_RUN_DIR=/absolute/path/to/run PHONE_SERIAL=DEVICE_SERIAL
make release-check PHONE_RUN_DIR=/absolute/path/to/run
```

Установка кандидата проверяет сохранённый APK и его manifest, затем выбирает физическое устройство. Она не пересобирает приложение. Проверка выпуска требует отдельных результатов функциональной проверки, производительности, батареи, доставки магазина и разрешения владельца. Формат этих локальных записей реализован в `scripts/phone-v2-release.py`.

Для проверки инструментов без постоянного ключа:

```sh
make release-test
```

Команда собирает unsigned release и использует временный тестовый ключ в тестовой папке. Подписанные кандидаты, `.env`, ключи и сырые результаты не добавляются в Git. Разрешение на распространение арта определяется [ASSET-LICENSE](../ASSET-LICENSE.md).
