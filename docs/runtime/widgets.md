# Часы на рабочем столе

Часы — native Android AppWidget с RemoteViews. Они обновляют время без Activity приложения: цифровые используют TextClock, стрелочные — AnalogClock. Минутный таймер в приложении для этого не нужен.

## Экземпляры

Каждый Android widget ID хранит собственное оформление, размер и действие по нажатию. Добавление, изменение, удаление и восстановление одного экземпляра не меняют соседние.

Размеры S/M/L задают композицию, а фактические размеры определяет launcher. Реализация учитывает размеры host и изменение доступной площади. S показывает время, M/L — время и дату; locale, часовой пояс и формат времени берутся из системы.

Нажатие открывает выбранное доступное приложение часов. Если оно удалено или недоступно, пользователь получает путь к повторному выбору. Виджет без сохранённой конфигурации показывает запрос настройки.

## Добавление и восстановление

Автоматическое добавление использует системный pin-запрос; ручное — список виджетов launcher. Конфигурация связывается с полученным widget ID. Неподтверждённые запросы очищаются, а известные экземпляры сверяются с Android при возвращении в приложение.

После восстановления Android может назначить новые ID: сопоставление и конфигурации обрабатываются в runtime. Размещение на экране блокировки зависит от доступного host и требует отдельной проверки; HOME остаётся основным маршрутом.

Код: `android/widgets/runtime`; экраны конфигурации и адаптер каталога — `android/hub/app/src/main/java/app/livosphere/widgets`.

При изменении runtime проверяйте два экземпляра, разные размеры, resize, удаление и восстановление. Геометрию нельзя принять только по картинке из каталога.
