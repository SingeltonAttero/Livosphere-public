# Дизайн

Редактируемый исходник и его зависимости находятся в [pen-design](../../pen-design/README.md). Текущие экраны описаны в [спецификации](../README.md).

Хаб имеет собственную светлую палитру и типографику. Цвет обоев не перекрашивает навигацию, кнопки и настройки. Экран «Обои» показывает арт на всю доступную площадь; элементы управления должны оставаться читаемыми на разных изображениях. Каталоги, «Ещё» и настройки используют обычную поверхность интерфейса.

Источник актуальных Compose-цветов, размеров и типографики — `android/hub/app/src/main/java/app/livosphere/hub/HubTheme.kt`. Минимальные touch targets — 48 dp; содержимое учитывает системные inset и увеличенный шрифт. Уменьшение движения должно сохранять все действия.

Превью обоев, карточка native-часов и установленное оформление — отдельные способы проверки. Новый арт согласуется с автором на конкретной ревизии. UI, документация экрана и рабочий дизайн обновляются в одном PR.
