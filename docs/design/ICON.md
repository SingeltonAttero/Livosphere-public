# Значок приложения

Арт «Живой мир» взят из pen.dev V1: фрейм `FU0ad`, мастер `beaY1`, источник `pen-design/generated-14.png` (1024×1024). Он используется как adaptive foreground с центровкой в безопасной области; фон — `#0C0824`, monochrome — отдельный векторный вариант.

Текущие Android-файлы: `android/hub/app/src/main/res/mipmap-*/ic_launcher*.png`, `mipmap-anydpi-v26/` и `drawable/ic_launcher_monochrome.xml`. Графика имеет отдельную авторскую лицензию [ASSET-LICENSE](../../ASSET-LICENSE.md).
