# Принятый planning baseline

Навигация — [docs/README.md](../README.md). Этот каталог хранит действующие PRD, UX, архитектурные контракты и backlog, перенесённые из BMAD. Исторические диагностические ссылки удалены; даты и статусы принятия сохранены. Источник требований не объявляется доказательством реализации.

Обновляйте документы в текущих workspaces. Настройка BMAD указывает сюда, а implementation artifacts и canonical sprint state — в `docs/development/`. Дополнительные временные review-выгрузки и сырые evidence сохраняйте в `.local/`.
