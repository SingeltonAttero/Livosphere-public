
# Два независимых сценария установки — 18 сентября 2026

Основание: владелец поручил «Epic 9: ну давай закрывать вроде все ок было» и уточнил: «нет смысла устанавливать виджет вместе с темой просто 2 разных флов».

- Обои: вкладка Обои/общий список → выбранная сцена → системная примерка Android → подтверждение.
- Виджеты: вкладка Виджеты → карточка конкретных часов → размер/действие → системное добавление. Новые часы не применяют обои и не заменяют существующие часы.
- Общая установка комплекта не нужна. В текущем consumer UX комплект не является отдельным обязательным шагом. Связь оформления остаётся художественной/каталожной.
- Текущая витрина, горизонтальные свайпы, отдельные карточки часов и native-v02 S/M/L приняты как рабочая основа сообщениями «так +- норм» и поручением закрыть Epic9. Локальные корректировки recovery/управления входят в его завершение.

Это заменяет прежние формулировки Epic9 о вкладке «Наборы» и переключателе поверхностей единой карточки. Epic9 принимается для текущих трёх зарегистрированных наборов и двух отдельных consumer flow. Техническое расширение schema2 для публикации отдельного widget-only manifest остаётся отдельным остатком AC-13.3-2; для закрытия Epic9 оно не требуется и не считается реализованным этим решением. Не создавать dummy wallpaper и не вводить shared install.

Публикация, release candidate и физическая батарея остаются в Epic14. Изменение маршрутов не закрывает их автоматически.
