# Порядок доставки самостоятельного контента

[Решение 17 сентября](sprint-change-proposal-2026-09-17.md) заменяет прежний последовательный план P1–P4 от 9 сентября. Фактический статус — только [sprint-status.yaml](../development/sprint-status.yaml), требования и зависимости — [epics.md](epics.md). [Дополнение 24 сентября](sprint-change-proposal-2026-09-24-pencil-wallpapers.md) добавило Epic 16 для десяти debug-обоев. Теперь 43 stories; номера сохраняют историю и не задают порядок выполнения.

9.1/9.2 переиспользуют минимальный маршрут 13.3, не являются входным gate для первого виджета. Story13.5 может стартовать с художественной работы до готовности motion runtime; её native выход требует завершённых применимых AC Epic10. Это не замкнутая зависимость. 13.4 следует новой 13.5 и 12.3 независимо от номера story.

Первый продукт не требует завершить все эффекты обоев, полноценную витрину или технический fixture rehearsal. Самостоятельный clock ещё нельзя упаковать текущей schema2: 13.3 включает явное версионированное расширение и сохранение прежних IDs/settings. Наличие подготовки не делает этот код готовым.

Для новой scene сохраняются четыре фазы, движение объектов, authored levels и power/reduced/off; для clock — S/M/L. Художественные revision approvals остаются у владельца. Никакая карточка, HTML или эмулятор не заменяют physical/battery/store evidence. Завершённые stories не переоткрываются автоматически, старое evidence не считается новым прогоном.

Следующий шаг: brief первого виджета через `$livosphere-content`, Story13.1. В этом поручении подготовлен процесс; стиль/арт не выбран. Новые производственные циклы начинаются отдельным поручением и режимом по AGENTS. Конец сентября остаётся прежним ориентиром, оценка уточняется после первого native-продукта; календарная скорость не выводится из количества stories.

## Checkpoint 18 сентября: два независимых flow

Владелец принял текущую витрину/виджеты за основу и поручил закрыть Epic9. Stories9.1–9.5 завершены для трёх текущих коллекций: evidence (исторический материал; не является зависимостью текущего документа). [Решение о раздельной установке](decision-2026-09-18-separate-install-flows.md) заменяет общий consumer путь комплекта. Отдельная упаковка widget-only из AC-13.3-2 остаётся техническим остатком и не блокирует Epic9; schema не менялась. Очередь выше сохраняет историю и не отменяет фактически готовый native-контент. Следующий checkpoint — ограниченный стартовый состав и зачёт существующего evidence процесса перед Epic14, без нового цикла подготовки тестовой сцены.
