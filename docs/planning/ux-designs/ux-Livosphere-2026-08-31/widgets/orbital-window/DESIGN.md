
# Орбита — часы Pencil V1

Статус: дизайн на HTML-ревью, `AP-HTML approved 2026-09-24`. Связанные обои: `orbital-window` («Окно на орбиту»). Тип: стрелочные. Стрелочный круг с орбитальными делениями на глубокем синем фоне. Художественная связь не требует установки обоев этого набора.

Источник: активная зафиксированная V1 Pencil, фреймы S (исторический материал; не является зависимостью текущего документа) `dnYIk` (160×160), M (исторический материал; не является зависимостью текущего документа) `m4SBgo` (280×160), L (исторический материал; не является зависимостью текущего документа) `sagao` (320×232). Общий интерактивный HTML-обзор (исторический материал; не является зависимостью текущего документа). Эти размеры — пиксели дизайн-фрейма, не обещание Android host bounds.

| Роль в Pencil M | Значение |
| --- | --- |
| Подложка | `#102735` |
| Основной акцент | `#7CBBC0` |
| Дополнительный акцент | `#E5F1EF` |
| Время/читаемый текст | `#E5F1EF` |
| Шрифт в экспорте | `Manrope` (дополнительный текст: Roboto) |

S показывает время, M/L — время и дату. Геометрия и декоративные детали каждого размера определяются его собственным Pencil-фреймом; масштабирование M вместо S/L не является принятым дизайном. Значения токенов взяты из M-фрейма и описывают источник, а не подтверждённую Android-палитру. Шрифтовая доступность и читабельность длинной локализованной даты требуют native-проверки после AP-HTML.
