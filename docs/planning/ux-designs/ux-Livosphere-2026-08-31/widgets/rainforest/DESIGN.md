
# Лесной круг — часы Pencil V1

Статус: дизайн на HTML-ревью, `AP-HTML approved 2026-09-24`. Связанные обои: `rainforest` («Лес после дождя»). Тип: стрелочные. Круглый стрелочный циферблат на тёмно-зелёной подложке. Художественная связь не требует установки обоев этого набора.

Источник: активная зафиксированная V1 Pencil, фреймы S (исторический материал; не является зависимостью текущего документа) `lBEwq` (160×160), M (исторический материал; не является зависимостью текущего документа) `Uzm34` (280×160), L (исторический материал; не является зависимостью текущего документа) `Dqhi6` (320×232). Общий интерактивный HTML-обзор (исторический материал; не является зависимостью текущего документа). Эти размеры — пиксели дизайн-фрейма, не обещание Android host bounds.

| Роль в Pencil M | Значение |
| --- | --- |
| Подложка | `#183C33` |
| Основной акцент | `#C9AD79` |
| Дополнительный акцент | `#F3E6C8` |
| Время/читаемый текст | `#F3E6C8` |
| Шрифт в экспорте | `Cormorant Garamond` (дополнительный текст: Roboto) |

S показывает время, M/L — время и дату. Геометрия и декоративные детали каждого размера определяются его собственным Pencil-фреймом; масштабирование M вместо S/L не является принятым дизайном. Значения токенов взяты из M-фрейма и описывают источник, а не подтверждённую Android-палитру. Шрифтовая доступность и читабельность длинной локализованной даты требуют native-проверки после AP-HTML.
