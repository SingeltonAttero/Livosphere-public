
# Тихая печать — часы Pencil V1

Статус: дизайн на HTML-ревью, `AP-HTML approved 2026-09-24`. Связанные обои: `moon-tide` («Лунный прилив»). Тип: цифровые. Светлая печатная композиция с красным знаком и графитовым временем. Художественная связь не требует установки обоев этого набора.

Источник: активная зафиксированная V1 Pencil, фреймы S (исторический материал; не является зависимостью текущего документа) `sotKH` (160×160), M (исторический материал; не является зависимостью текущего документа) `EZUJ0` (280×160), L (исторический материал; не является зависимостью текущего документа) `rGsOK` (320×232). Общий интерактивный HTML-обзор (исторический материал; не является зависимостью текущего документа). Эти размеры — пиксели дизайн-фрейма, не обещание Android host bounds.

| Роль в Pencil M | Значение |
| --- | --- |
| Подложка | `#F5F0E6` |
| Основной акцент | `#A34438` |
| Дополнительный акцент | `#333B43` |
| Время/читаемый текст | `#333B43` |
| Шрифт в экспорте | `Noto Serif` (дополнительный текст: Roboto) |

S показывает время, M/L — время и дату. Геометрия и декоративные детали каждого размера определяются его собственным Pencil-фреймом; масштабирование M вместо S/L не является принятым дизайном. Значения токенов взяты из M-фрейма и описывают источник, а не подтверждённую Android-палитру. Шрифтовая доступность и читабельность длинной локализованной даты требуют native-проверки после AP-HTML.
