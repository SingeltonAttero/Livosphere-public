
# Тихая печать — поведение часов

Revision: Pencil V1 / HTML-review-v1. Статус: `AP-HTML approved 2026-09-24`; Android-реализация этих часов пока не заявлена.

- Самостоятельный AppWidget на HOME: S — время, M/L — время и локализованная дата. У цифровых часов системное время, часовой пояс и 12/24-часовой формат должны обновляться без минутного polling приложения.
- Тап по всей читаемой области ≥48dp откроет выбранное владельцем приложение часов. В HTML это только пояснение; установка и запуск приложения не имитируются.
- Размер выбирается в конфигурации/host, реальные bounds и padding могут отличаться от 160/280/320 px Pencil. Несколько экземпляров имеют независимые target и настройки.
- Эти часы можно использовать с обоями другого набора. Смена фаз обоев не меняет часы и не переносит в AppWidget их анимацию.
- Сценарии HTML-обзора (исторический материал; не является зависимостью текущего документа): 09:41, 00:00, 11:11, 23:59, длинная дата и 12-часовой формат; светлый и тёмный фон. В Android проверяются читаемость, host clipping, TalkBack, font scale и выбранное clock app.

Общий [контракт поведения](../EXPERIENCE.md) остаётся основой; локальный документ фиксирует связь с этим продуктом.
