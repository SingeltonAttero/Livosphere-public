
# Атлас — часы Pencil V1

Статус: дизайн на HTML-ревью, `AP-HTML approved 2026-09-24`. Связанные обои: `star-river` («Звёздная река»). Тип: цифровые. Светлая типографическая карта времени с золотистым акцентом. Художественная связь не требует установки обоев этого набора.

Источник: активная зафиксированная V1 Pencil, фреймы S (исторический материал; не является зависимостью текущего документа) `sxFam` (160×160), M (исторический материал; не является зависимостью текущего документа) `yzddX` (280×160), L (исторический материал; не является зависимостью текущего документа) `HVTE6` (320×232). Общий интерактивный HTML-обзор (исторический материал; не является зависимостью текущего документа). Эти размеры — пиксели дизайн-фрейма, не обещание Android host bounds.

| Роль в Pencil M | Значение |
| --- | --- |
| Подложка | `#F0EBDF` |
| Основной акцент | `#AD8253` |
| Дополнительный акцент | `#354F6C` |
| Время/читаемый текст | `#354F6C` |
| Шрифт в экспорте | `Bodoni Moda` (дополнительный текст: Roboto) |

S показывает время, M/L — время и дату. Геометрия и декоративные детали каждого размера определяются его собственным Pencil-фреймом; масштабирование M вместо S/L не является принятым дизайном. Значения токенов взяты из M-фрейма и описывают источник, а не подтверждённую Android-палитру. Шрифтовая доступность и читабельность длинной локализованной даты требуют native-проверки после AP-HTML.
