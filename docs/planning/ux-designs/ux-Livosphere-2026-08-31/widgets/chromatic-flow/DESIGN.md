
# Ритм — часы Pencil V1

Статус: дизайн на HTML-ревью, `AP-HTML approved 2026-09-24`. Связанные обои: `chromatic-flow` («Хроматический поток»). Тип: цифровые. Графичный ритм крупного времени, бирюзовых и тёплых акцентов. Художественная связь не требует установки обоев этого набора.

Источник: активная зафиксированная V1 Pencil, фреймы S (исторический материал; не является зависимостью текущего документа) `r79aq` (160×160), M (исторический материал; не является зависимостью текущего документа) `A40cdc` (280×160), L (исторический материал; не является зависимостью текущего документа) `qdPr2` (320×232). Общий интерактивный HTML-обзор (исторический материал; не является зависимостью текущего документа). Эти размеры — пиксели дизайн-фрейма, не обещание Android host bounds.

| Роль в Pencil M | Значение |
| --- | --- |
| Подложка | `#12383C` |
| Основной акцент | `#4D9D9A` |
| Дополнительный акцент | `#D29448` |
| Время/читаемый текст | `#FAEDD3` |
| Шрифт в экспорте | `Anton` (дополнительный текст: Roboto) |

S показывает время, M/L — время и дату. Геометрия и декоративные детали каждого размера определяются его собственным Pencil-фреймом; масштабирование M вместо S/L не является принятым дизайном. Значения токенов взяты из M-фрейма и описывают источник, а не подтверждённую Android-палитру. Шрифтовая доступность и читабельность длинной локализованной даты требуют native-проверки после AP-HTML.
