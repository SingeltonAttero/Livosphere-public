
# Лунный прилив — EXPERIENCE

Текущий этап: четыре неподвижных кадра и автоматическая смена по местному времени устройства. Утро 05:00–08:00, день 08:00–18:00, вечер 18:00–21:00, ночь 21:00–05:00. Переход мгновенный, без fade/crossfade.

Новый Engine начинает с актуальной фазы; видимый Engine пересчитывает её на границе, после возврата видимости, изменения времени/даты/часового пояса и пересоздания. Невидимый Engine не держит render loop или timer. При выборе полотна приложение показывает один случайный фазовый кадр без ручных кнопок; повторный выбор может показать другой кадр. Этот выбор не меняет установленный wallpaper или автоматический режим. Системные preview/confirm/cancel и наблюдение HOME остаются штатными.

Движение объектов, particles, parallax, tap/swipe, blink/pulse и эффекты зарядки в этой ревизии отсутствуют по [решению владельца](../../../../sprint-change-proposal-2026-09-24-pencil-wallpapers.md). Карта движения и AP-HTML для будущей анимации готовятся отдельно, без обещания такого поведения текущим APK.
