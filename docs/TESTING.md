# Проверка на устройстве

Сначала соберите и установите debug APK:

```sh
make phone
./scripts/android-env.sh adb devices
make phone-install PHONE_SERIAL=DEVICE_SERIAL
```

После успешной установки команда запускает главную Activity Livosphere. Если запуск не подтверждён, команда сообщает об ошибке; APK остаётся установленным.

Не запускайте установку без выбора устройства, если их несколько. После изменения кода повторите сборку и установку; `install -r` сохраняет данные при совместимой подписи.

## Маршрут проверки

| Шаг | Ожидаемый результат |
| --- | --- |
| Открыть приложение; закрыть инструкцию | Можно сразу пользоваться коллекцией |
| Листать обои; открыть «Все обои» и выбрать карточку | Возврат к выбранным обоям; текущие обои телефона не меняются |
| Нажать «Установить обои» и отменить Android-примерку | Прежнее оформление остаётся |
| Повторить и подтвердить установку | Выбранные обои работают после закрытия приложения |
| Открыть «Виджеты», выбрать часы и S/M/L | Карточка показывает выбранный размер и действие по нажатию |
| Добавить два экземпляра, в том числе из другой коллекции | Каждый сохраняет собственное оформление |
| «Ещё» → «Помощь с установкой» → изменить один экземпляр | Второй экземпляр не меняется |
| Изменить размер в launcher и удалить один экземпляр | Часы помещаются в доступную площадь; список обновляется после возврата |
| Изменить доступные настройки обоев и перезапустить приложение | Выбор сохраняется; неподдержанные параметры не показываются |
| Включить экономию энергии, заблокировать и разблокировать телефон | Обои соблюдают ограничение движения; часы показывают актуальное время |
| Изменить язык/формат времени/часовой пояс в системе | Время и дата обновляются; фаза обоев соответствует местному времени |

Если автоматическое добавление виджета недоступно, добавьте его из списка виджетов launcher. Проверка LOCK нужна только там, где устройство предоставляет соответствующий host.

## Автоматические проверки

```sh
make check
make scripts-check
make device-check
```

Последняя команда требует подключённого устройства. Проверяйте resize, несколько экземпляров и восстановление после перезагрузки вручную при изменении widget runtime.

Для сообщения об ошибке укажите модель телефона, Android, launcher, версию приложения, шаги и ожидаемый результат. Для батареи/плавности дополнительно нужны длительность, яркость, baseline и точный APK. Не коммитьте сырые логи или персональные снимки экрана.
