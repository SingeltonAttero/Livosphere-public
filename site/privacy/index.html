Livosphere

Политика конфиденциальности

Дата вступления в силу и последнего обновления: 1 октября 2026 года.

Livosphere работает локально на вашем Android-устройстве. Приложение не требует аккаунта и не отправляет данные об использовании разработчику.

1. Приложение и разработчик

Эта политика относится к Android-приложению Livosphere («Живые обои Livosphere», идентификатор пакета app.livosphere) — коллекции авторских живых обоев и виджетов часов.

Разработчик: Вебер Яков (Yakov Weber). Обращения по вопросам конфиденциальности принимаются через GitHub Issues проекта Livosphere.

2. Сбор данных

Livosphere не собирает и не передаёт разработчику персональные данные, рекламные идентификаторы, статистику использования или отчёты об ошибках. В приложении нет рекламы, сервисов аналитики, регистрации и серверной синхронизации.

Приложение не запрашивает доступ к контактам, сообщениям, микрофону, камере или географическому местоположению. Для работы каталога, обоев и часов подключение к интернету не требуется.

3. Данные, обрабатываемые на устройстве

Чтобы выполнять выбранные вами действия, приложение обрабатывает следующие сведения локально:

  • Настройки оформления: выбранная коллекция, режим движения, интенсивность эффектов и включение реакций на касания и наклон.
  • Настройки часов: оформление и размер каждого виджета, его системный идентификатор и выбранное действие по нажатию, включая компонент приложения часов, которое нужно открыть.
  • Настройки интерфейса: параметры движения, просмотра коллекций и сведения о показе инструкции и сообщения об обновлении.
  • Время и часовой пояс: для отображения часов и изменения сцен в зависимости от местного времени.
  • Касания и наклон устройства: координаты касаний, показания датчика гравитации или акселерометра для интерактивных эффектов в поддерживаемых обоях. Эти показания обрабатываются во время работы эффекта, не сохраняются как история и не передаются разработчику. Реакции можно отключить в настройках.
  • Системные сведения Android: доступность функций живых обоев, текущий компонент живых обоев, состояние экземпляров часов, режим энергосбережения и ограничения батареи, настройки уменьшения движения, параметры экрана и доступные приложения для открытия будильников. Они нужны для установки, отображения и помощи с настройкой обоев и часов.

Приложение проверяет доступность компонентов, необходимых для этих функций; оно не составляет и не отправляет разработчику полный список установленных приложений.

4. Передача данных и системные функции

Livosphere не передаёт локальные настройки и показания датчиков на серверы разработчика или рекламным и аналитическим сервисам и не продаёт пользовательские данные.

Для установки обоев, размещения виджетов и открытия часов приложение взаимодействует с Android, программой домашнего экрана и выбранным приложением часов. Им передаются необходимые параметры действия, например компонент обоев, идентификатор виджета или команда открытия будильников. Обработка данных этими системными и сторонними приложениями определяется их собственными правилами.

5. Хранение, защита и удаление

Сохранённые настройки находятся в выделенном Android хранилище приложения на вашем устройстве. Доступ к нему ограничивается средствами безопасности Android. Серверной копии настроек у разработчика нет.

Настройки хранятся, пока они нужны для работы приложения, либо до очистки его данных или удаления приложения. Чтобы удалить локальные настройки, используйте системный раздел Android «Приложения → Livosphere → Хранилище → Очистить данные» либо удалите приложение. Названия пунктов могут отличаться на разных устройствах.

Очистка данных сбрасывает настройки обоев и часов. Установленные обои и размещённые виджеты управляются также Android и программой домашнего экрана; при необходимости смените обои и удалите виджеты средствами устройства.

6. Обращения по конфиденциальности

Вы можете задать вопрос о данных приложения или направить запрос через новое обращение в GitHub Issues. Для отправки обращения потребуется аккаунт GitHub; для чтения этой политики и использования Livosphere он не нужен.

Если вы добровольно отправляете обращение, разработчик получает ваш публичный профиль GitHub и содержание сообщения и использует их для ответа и решения вопроса. Обращения хранятся в GitHub Issues для рассмотрения запроса и последующей поддержки. Вы можете запросить удаление опубликованных вами сведений через тот же канал; возможности удаления и сроки хранения данных на стороне GitHub определяются правилами GitHub.

GitHub Issues — публичный канал. Не включайте в сообщение пароли, документы, адреса, контакты или другие конфиденциальные сведения. Для вопроса о локальных настройках обычно достаточно описания ситуации без персональных данных.

7. Веб-страница политики

Эта страница размещена на GitHub Pages. Она не содержит подключённых разработчиком счётчиков аналитики, рекламы, внешних шрифтов или скриптов отслеживания.

При посещении страницы GitHub может обрабатывать технические сведения веб-запроса, включая IP-адрес, время запроса и сведения о браузере. При использовании GitHub Issues GitHub также обрабатывает данные вашего аккаунта и сообщения. Подробнее: политика конфиденциальности GitHub. Эти веб-запросы не являются отправкой данных приложением Livosphere.

8. Изменения политики

При изменении работы приложения или способов обработки данных разработчик обновит эту политику. Актуальная редакция публикуется по этому адресу с новой датой обновления.
