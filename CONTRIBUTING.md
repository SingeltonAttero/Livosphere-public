# Разработка Livosphere

Прочитайте [спецификации экранов](docs/README.md) и [инструкцию сборки](docs/BUILDING.md). Приложение собирается обычными Android-инструментами; набор редакторов, агентов и навыков выбирает разработчик.

Сделайте небольшое изменение с понятным результатом. Сохраните логику состояния вне Compose, не редактируйте generated-ресурсы вручную. Вместе с изменением поведения обновите соответствующую документацию; для UI — также рабочий дизайн.

Перед PR выполните подходящие тесты, сборку и `git diff --check`. Укажите команды, результат и ручной путь проверки. Не коммитьте ключи, `.env`, локальные SDK-пути, APK/AAB или сырые логи. Новый авторский арт согласуется с владельцем; сохраняйте лицензии и источники ресурсов.
